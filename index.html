  • 담당 범위: Flutter 코치용 모바일 앱 전체 개발 및 백엔드 개발자가 구현한 LangChain 기반 다중 LLM 서버와 API 연동
  • 프롬프트 협업: 디자이너·프론트엔드·백엔드 공동 작성 및 초기 답변의 어색한 말투에 대한 지침 보완
  • 입력 정보: 음식명·섭취량·칼로리, 회원 목표·체중·과거 식단의 텍스트 전달
  • 생성 옵션: 앱 내 모델·말투·답변 길이·피드백 분위기 선택 UI 구현
  • 스트리밍 UI: 응답의 점진적 표시 및 생성 중 버튼 비활성화
  • 오류 처리: 생성 실패 시 Snackbar 안내 및 수동 재시도 흐름 구현
  • 검토 후 전송: 초안 수정·재생성 및 코치의 전송 버튼을 통한 회원 전달 흐름 구현
  • 운영 확인: Slack webhook의 생성·전송 이벤트를 통한 실제 활용 여부 확인
  • 도입 한계: IT 활용에 익숙한 코치의 사용과 기존 수기 방식 선호 코치의 사용 장벽 확인
  • 회원용 앱의 컴포넌트를 모노레포로 재사용해 코치용 앱 출시
